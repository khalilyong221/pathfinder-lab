# PathFinder Lab · 寻路算法可视化实验室

一个零依赖的纯前端寻路算法可视化工具,用一张网格实时演示 **BFS / DFS / Dijkstra / A\*** 四种经典算法的搜索过程。

## 在线体验

打开 `index.html` 即可运行(无需构建、无需安装依赖)。

## 功能

- **四种算法**:广度优先搜索(BFS)、深度优先搜索(DFS)、Dijkstra 最短路径、A\*(曼哈顿距离启发式)
- **交互式网格**:拖动起点 / 终点,按住鼠标绘制墙体
- **随机迷宫生成**:基于随机化深度优先回溯(Randomized DFS / recursive backtracker)在奇偶网格上生长迷宫,保证起点到终点在拓扑上必然连通,不会出现生成的迷宫把终点堵死的情况
- **动画回放**:逐帧展示节点访问顺序与最终最短路径,速度可调
- **运行统计**:访问节点数、路径长度、求解耗时、是否可达

## 技术实现

纯 HTML / CSS / JavaScript,无第三方框架或依赖:

- 网格用普通 DOM 节点渲染,通过 CSS class 切换 + `@keyframes` 做访问/路径动画
- 四种算法各自实现在独立函数中(`bfs` / `dfs` / `dijkstra` / `astar`),统一返回 `{ visitedInOrder, path }`,便于比较不同算法的搜索顺序与效率差异
- 迷宫生成使用经典的"奇偶网格"技巧:把网格上 (奇数行, 奇数列) 的格子当作"房间",随机化 DFS 在房间之间打通墙壁,天然保证生成的迷宫是一棵连通的生成树(没有孤立区域,也没有环)
